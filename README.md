# micro-learning-app

Welcome to the micro-learning app built with React and Vite.

This repository contains a full-screen swipeable card demo with animated indicator boxes and vertical paging.

## Local changes merged

- Animated cards with paged vertical scroll
- Cycling visual indicators for each card
- Responsive styling for desktop and mobile

## Available Scripts

In the project directory, you can run:

### `npm start`

Runs the app in development mode and opens the local dev server.

### `npm run build`

Bundles the app for production.

### `npm test`

Runs the test suite using Vitest.
